Security Policy ()
Definition: Security Policy ABB is a Business Object that regulates the protection of customer or client's data. Source: Gartner Source reference: https://www.gartner.com/en/information-technology/glossary/security Example: The following implementation is an example on how this specific Architecture Building Block (ABB) can be instantiated as a Solution Building Block (SBB): Common Foreign and Security Policy (CFSP) - The Common Foreign and Security Policy (CFSP) is the organised, agreed foreign policy of the European Union (EU) for mainly security and defence diplomacy and actions. https://eeas.europa.eu/topics/common-foreign-security-policy-cfsp_en IoP Dimension: Governance IoP LOST view: Semantic view Interoperability saliency: The Security Policy ABB is salient for semantic interoperability because it provides a guiding framework to ensure the security of data and information according to interoperability principles as stated in the EIF recommendation n° 46 and 47: "Consider the specific security and privacy requirements and identify measures for the provision of each public service according to risk management plans."
